Badge instructions

How to use your DEF CON 34 badge.

Gestures

  • Swipe down — Open mode selector
  • Swipe up — Credits & QR code
  • Swipe left — Settings menu
  • Swipe right — System menu
  • Tap — Select / confirm
  • Hold 3 sec — Open credits (from home)

Menus

  • Mode — Switch between nametag, BLE scanner, 2048, and scenes
  • Settings — Set your name, enable MQTT, toggle popup text & scan sharing
  • System — Adjust brightness, battery icon, OTA update, factory reset

Display

  • Tap FLIP in the bottom-right of any menu to rotate the display 180°
  • Brightness cycles through 25%, 50%, 75%, and 100%

Remote control

  • Enable MQTT in Settings, connect to the same WiFi, and pair above to send commands from this page
  • You can change the name, switch modes, and send popup messages remotely
